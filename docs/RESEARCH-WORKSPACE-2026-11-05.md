# 문헌조사 작업 공간 개선 · 2026-11-05

승인된 ‘두 시작 경로 → 근거 비교 → 보고서’ 구조를 실제 Streamlit 앱에 반영했다. 기본 운영 방식은 로컬 보관, AI 없이 읽기·정리·내보내기, 선택적인 AI 연결이다.

## 비교에서 선택한 방향

아래는 2026-11-02에 확인한 공식 안내다. 유료 계정의 전체 화면을 직접 비교하거나 정확도를 측정한 평가가 아니다. ‘경쟁 도구는 전부 유료’, ‘이 기능은 다른 도구에 없다’고 단정하지 않는다.

| 확인한 조건 | 이번에 해결한 사용자 작업 |
|---|---|
| Elicit 보고서는 모든 플랜에서 PDF·Word로 내보낼 수 있다. Research Agent 표는 Plus 이상, Systematic Review 표는 Pro 이상에서 내보낸다. | AI를 실행하지 않은 조사도 노트·서지·검색 이력으로 가져가기. 검토한 AI 근거 결과는 별도 ZIP으로 보존. |
| Liner 무료 플랜은 파일 업로드가 하루 1개·최대 25MB이며 상위 플랜에서 한도가 늘어난다. | 앱에 저장한 텍스트 PDF를 로컬에서 검색하고 발췌·메모하기. 앱의 업로드 크기·메모리 한도는 여전히 적용됨. |
| ResearchRabbit 무료 플랜도 인용·참고문헌 탐색, 컬렉션, 노트, BibTeX 가져오기·내보내기를 제공한다. | 후보 수집 자체의 독점성을 주장하지 않고, 읽을 이유 → 원문 위치 → 메모 → 사람의 근거 판단을 연결. |
| OpenAlex의 현재 안내는 소규모 무키 사용과 무료 키의 확대된 일일 예산, 초과 사용의 별도 과금을 구분한다. | 앱 이용료와 외부 자료원·AI 이용 조건을 구분. 무제한 무료 검색을 약속하지 않음. |

## 구현된 기능

1. **시작:** 조사 질문 또는 PDF에서 시작한다. 사용자 질문을 저장하고 프로젝트 폴더 이름은 자동 생성한다. 신규 조사에 예제의 선별 기준을 강제로 넣지 않는다.
2. **작업 공간:** 문헌 모으기 → 근거 비교 → 보고서에 쓰기. 조사 설정과 학습 모드는 보조 동작으로 유지한다.
3. **후보함:** 검색 결과를 영구 저장한다. 먼저 읽기·나중에·읽음, 읽을 이유, 발견한 검색어를 기록한다. 같은 DOI 후보를 다시 저장해도 기존 읽기 메모와 확보한 PDF 연결을 보존한다.
4. **로컬 읽기:** 등록된 PDF의 텍스트 구간을 AND 키워드로 검색한다. 검색 결과에는 문헌·PDF 쪽·원문 구간이 연결된다. 의미 검색이나 학술적 관련도 순위는 아니다.
5. **독서 노트:** 원문에 실제로 있는 발췌와 연구자의 메모를 쪽수·위치와 함께 저장한다. 노트에서 원문으로 다시 이동한다. AI 결과를 자동 채택하거나 종합에 넣지 않는다.
6. **근거 비교:** 기본 화면은 비교표와 선택한 근거를 나란히 보여 준다. 집중 검토에서는 PDF 강조를 확인한다. 수정 입력란은 ‘수정 후 채택’일 때만 표시한다. 위치 일치·의미적 지지·사람의 판단을 구분한다.
7. **자료 이동:** AI 실행 전에도 노트 Markdown, 참고문헌 RIS, 자료 ZIP을 생성한다. ZIP에는 검색 이력 CSV·후보·설정·노트 JSON과 선택적인 원본 PDF가 들어간다. AI 실행·검토 기록은 기존 결과 ZIP으로 받는다.
8. **AI 선택:** 기존 Claude Code·웹 AI 경로에 더해 설정된 Chat Completions API를 화면에서 실행할 수 있다. 로컬 주소인지 외부 주소인지, 어떤 원문이 전달되는지 표시한다. API 키는 환경변수로만 읽고 내보내지 않는다.
9. **저장 위치:** 기본 `projects/`, 선택적으로 `DRK_PROJECTS_DIR`. 자료는 앱 서버가 실행되는 컴퓨터에 저장된다.

- 새 질문 저장, 새 프로젝트의 예제 기준 제거, 원문 키워드 검색, 존재하지 않는 발췌 거부, 원본 변조 감지, 노트 중복 저장 방지, 후보 메모·PDF 연결 보존을 자동 검증했다.
- AI 없이 생성한 자료 ZIP의 노트·서지·검색 이력·PDF 내용, CSV 수식 방어, API 키 미포함을 검증했다.
- UI 자동 검사에서 새 조사 → PDF 작업, 원문 검색 → 노트 저장 → 결과 화면 → 동일 원문 구간으로 복귀, 조건부 수정 입력란을 확인했다.
- 브라우저에서 실제 논문의 근거 전환에 따라 PDF 1쪽 → 12쪽 이동 및 강조, 다음 논문으로 문서·강조 교체를 확인했다.
- 별도 임시 프로젝트 복사본에서 `overgeneralizing` 검색 → PDF 12쪽 발췌·메모 저장 → 결과 화면 표시를 확인했다. 원본 예제의 검토 판단은 바꾸지 않았다.

## 이번 범위의 한계

- 로컬 AI 모델 설치·실제 추론과 외부 유료 AI 실계정 호출은 검증하지 않았다. API 형식·서버별 컨텍스트 한도에 따라 연결이 실패할 수 있다.
- 로컬 주소가 외부 서버로 중계될 가능성은 해당 모델 서버 설정에 달려 있다. 앱의 로컬 저장을 오프라인 AI 실행 보장으로 표현하지 않는다.
- OCR, 인용 네트워크, 변경분만 재추출, Word 보고서 직접 출력, 웹 계정·동기화·공동 편집은 추가하지 않았다.
- 자료 ZIP은 자동 복원 가능한 전체 프로젝트 백업 형식이 아니다.
- 독서 노트는 발췌와 메모를 기록하는 기능이며, 메모의 학술적 타당성을 검증하지 않는다. 검색 포괄성이나 자동 문헌고찰 완성을 보장하지 않는다.
