# 검증 기록 · 0.1.0

검증일: 2026-10-30. 운영체제 macOS, Python 3.11.5. 검증된 동작과 남은 환경 의존성을 구분한다.

## 자동 검증

`pytest` 15개 통과. 실제 PDF를 생성해 아래 실패 조건을 시험했다.

- 정확한 원문 인용과 좌표, 반복 문장의 ambiguous 처리, 없는 인용과 없는 passage ID.
- 한글을 제거하지 않는 정규화, 텍스트 없는 페이지, 회전 페이지의 자동 검증 제외.
- 동일 파일의 중복 등록 방지와 동일 연구의 여러 보고서 구분.
- 허위 인용 채택 차단, 모델이 넣은 review 상태 무시.
- 누락 추출 항목, 다른 실행의 응답, 조사 범위 밖 인용 거부.
- 사람이 보류로 바꾼 근거가 기존 종합을 만료시키는지 확인.
- 미검토 근거가 종합 주장에 연결되는 것을 차단.
- 추출 항목 변경 후 새 요청·새 추출, 기존 실행 파일 보존, 변경 비교.
- 원본 파일 변조 시 검토·내보내기 차단, 재시작 후 기록 보존.
- Markdown·JSON·CSV와 원문 위치·검토 이력 내보내기.
- 선택 API의 JSON 계약, 오류 처리, 키를 응답·오류에 노출하지 않는 처리(모의 HTTP 응답).
- Streamlit 초기 화면의 런타임 예외 검사.

Ruff 정적 검사와 스킬 `quick_validate.py` 형식 검사 통과. CI에는 macOS·Windows·Linux 검증 구성을 넣었지만, 원격 CI가 실제로 실행된 것은 아니다.

수업용 ZIP을 별도 빈 폴더에 풀어 모든 파일의 SHA-256을 확인했다. 새 가상환경에 잠금 파일대로 설치한 뒤 15개 테스트와 Ruff 검사를 통과했다. 설치 시험은 이미 받아 둔 의존성 캐시를 이용했으므로, 학생의 최초 네트워크 다운로드 속도까지 검증한 것은 아니다. ZIP 안의 원문 캐시만으로 3편을 등록하고 12개 기준 근거를 불러오는 오프라인 자료 준비도 확인했다. 내보내기에 문헌 비교 CSV와 원본 PDF의 해당 쪽 링크가 포함되는지 확인했다.

## 실제 자료와 화면

- 실제 논문 3편을 원본 PDF로 등록: 51쪽, 131쪽, 12쪽(리포지터리 표지 포함).
- 기본 첫 20쪽 범위를 요청·근거·보고서에 명시한다. 긴 부록까지 읽으려면 제한을 0으로 바꾼다.
- 사전 작성한 12개 추출 예시를 각 PDF의 원문 위치에 연결했다. 12개 모두 matched, 사람의 검토 상태는 모두 pending이다.
- 별도 Chrome 테스트 프로필에서 실제 PDF 캔버스와 원문 텍스트 레이어를 확인했다.
- 같은 문헌의 첫 페이지 근거에서 12쪽의 적용 한계 근거로 선택을 바꾸어 페이지·강조가 갱신되는 것을 확인했다.
- UI 다운로드로 ZIP을 받은 뒤 12개 근거·검토 상태·종합 없음 상태가 보존되는지 읽어서 확인했다.
- 앱 내 브라우저 자동화는 환경의 glob 경로 설정 오류로 시작되지 않았다. 별도 Chrome/Playwright로 검증했다.

## 새 질문·항목 변경 사례

공통 사전 예시와 별도로, METR 원문 1~2쪽에 대해 “실측 완료 시간과 자기보고가 어떻게 다른가?”라는 질문을 만들었다.

1. Codex가 현재 요청과 제공된 원문을 읽고 `measured_outcome`, `self_report` 두 항목을 새로 작성했다. 공통 예시 응답을 재사용하지 않았다.
2. 두 인용이 실제 원문에 연결되는지 확인하고 개발 검증용 판단을 기록했다. 검토자 이름을 **“Codex 개발 검증 (사람 검토 아님)”**으로 표시했으며 학생용 공통 사례와 분리했다.
3. 종합에 두 근거 ID를 연결하고 범위·일반화 한계를 보존했다.
4. `forecast` 항목을 추가하고 같은 원문에서 사전 예상 24%, 사후 추정 20%, 실측 완료 시간 증가 19%를 구분하는 새 응답을 작성했다.
5. 기존 실행의 evidence.json bytes가 바뀌지 않았고, 새 항목과 값·검토 상태의 차이가 비교 결과와 각각의 내보내기에 남았다.

## 미검증·환경 제약

- Claude Code CLI의 실제 모델 호출은 `Not logged in · Please run /login`으로 실패했다. 사용자 로그인 세션의 `/deep-research` 자동 실행은 이 환경에서 끝까지 확인하지 못했다. 스킬 형식, 지시문, 동일 CLI/JSON 전달 경로와 Codex를 통한 새 추출은 확인했다.
- 유료 외부 API 계정의 실제 추론 호출은 미검증이다. 모의 HTTP 계약 검증을 외부 실계정 성공으로 표시하지 않는다.
- Windows·Linux의 설치·실행은 로컬에서 확인하지 못했다. 배포 공지 전 해당 학생 환경에서 시작 명령을 확인하는 것이 좋다.
- OCR, 표 구조, 회전·cropbox가 다른 페이지의 자동 강조, 모든 다단 문서의 정확한 읽기 순서는 보장하지 않는다. 미지원·실패 상태를 확정 근거로 승격하지 않는다.
- 사전 예시는 동일한 PDF 해시와 기본 설정에서만 로드된다. 설정을 바꾼 뒤에는 실제로 새 추출을 해야 한다.
- 결과의 학술적 완전성·검색 포괄성·사실성 인증을 보장하는 벤치마크는 수행하지 않았다.
