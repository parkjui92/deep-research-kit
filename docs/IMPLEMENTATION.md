# Deep Research Kit 0.1.0 구현 범위

로컬 개발과 배포 ZIP 준비를 완료했다. 실제 검증과 미검증 환경은 `VALIDATION.md`를 확인한다. GitHub 원격 저장소 게시와 원격 CI 실행은 아직 하지 않았다.

## 이번 범위

- 독립 프로젝트: 기술영향평가는 예제이며 질문·범위·선별·추출 항목·종합 규칙은 수정 가능.
- 6단계 Streamlit UI와 프로젝트 로컬 Claude Code 스킬, 공통 Python CLI.
- PDF 등록, 해시 기반 중복 방지, 문헌과 연구 단위 구분, 선별 이유, 선택 Crossref 검색 기록.
- 텍스트와 원문 좌표 색인, 1부터 시작하는 PDF 쪽수, 명시적인 읽기 범위.
- 실제 원본 PDF 렌더링, 근거 위치 강조·페이지 전환·확대.
- 정확 정규화 대조 / 반복·미발견 / 위치 미지원 / 사람의 검토 판단을 분리.
- 채택·수정·보류·제외, 검토 이력, 수정 시 종합 만료.
- 채택 근거 기반 종합과 미확인 항목 분리, 근거 목록·문헌 비교 CSV.
- 새 기준으로 원문을 다시 읽는 실행, 이전 기준·추출·검토 보존, 실행 비교.
- Markdown·JSON·CSV·선택 원본 PDF 내보내기, 문헌·근거 ID와 위치·검토 상태 보존.
- 공통 실제 논문 3편, 명시적인 사전 작성 예시(모두 미검토), 새 질문에 대한 별도 동작 검증.
- 설치 안내, macOS/Windows 시작 파일, GitHub 이슈 양식, CI 구성, 라이선스 고지와 패키지 생성기.

## 10주차와의 경계

9주차는 개별 문헌조사와 근거 검토까지 다룬다. 결과를 위키의 재료로 넘기며, 위키 편집·문서 연결·지식 그래프·다중 사용자 협업은 이번 도구 범위에 넣지 않았다. 14~16주차 팀 프로젝트용 기능도 추가하지 않았다.

## 실행 환경

기본은 사용자가 로그인한 에이전트의 스킬 실행이다. AI 서비스 이용량은 해당 서비스 조건을 따른다. 직접 API 경로는 선택 기능이며 키는 환경변수로만 받는다. 기본 UI는 localhost 전용이다.

OCR, 표 구조 인식, 웹 원문 아카이빙, 회전·cropbox가 다른 페이지의 자동 강조, 전 세계 학술 인용 맥락 데이터베이스는 이번 버전에 포함하지 않는다. 미지원 페이지는 원문을 보여주되 검증된 근거로 자동 채택하지 않는다.
