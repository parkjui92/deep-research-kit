### 심각도 2·1 중 반영한 것
- "원문에서 찾지 못한 구절 … (같은 문장이 여러 곳)" 모순 문구(전원) → 여러 곳에 있으면 전부 위치로 인정(`multiple`), 못 찾았을 때는 해결 방법을 적음
- 저장 뒤 「검토할 문헌」이 1번으로 되돌아감(u2) → 선택 유지
- 단계 이동 시 스크롤 위치가 이어짐(u2) → 새 단계는 맨 위에서
- 3단계 '응답 있음' 펼침에 값이 안 보임(u2) → 추출값 미리보기 + 4단계 안내
- 영문 코드 노출 `exact_normalized`·`matched`·`accept`(u2·u3·u5) → 화면·보고서·CSV 모두 한국어 낱말
- '검토 중'·'없음·만료'(u5) → '응답 도착 · 검토 가능', 종합문 상태를 '아직 없음 / 요청함 · 결과 대기 / 만료 · 판단이 바뀜 / 유효'로
- UTC 시각(u2·u3) → 한국 시각, 사이드바 긴 경로·Deploy 버튼(u2·u3) → 폴더 이름만, 툴바 숨김
- 응답 없는 빈 실행이 비교 기준 기본값(u2·u5) → 응답 있는 실행만 비교 기준
- 내려받기 파일 이름에 프로젝트 이름(u3·u5), 보고서 머리에 프로젝트·작성 시각·검토자, 반복 메모 1회, `evidence.csv` 한글 머리글(u3)
- 2단계 사이드바가 PDF 등록 뒤에도 ○(u5) → 문헌이 있으면 ✓
- "9주차·10주차 위키" 수업 문구(u2·u3·u5) → 중립 문구
- 첫 화면이 용도를 말하지 않음(전원 "반쯤") → 제목·부제·사이드바 한 줄에 "AI가 뽑은 값을 사람이 원문으로 확인 · AI 실행은 Claude Code 또는 수업용 예시"
- 사용자 지적 "처음에 예시가 다 채워져 있어 뭘 하라는지 모름" → 단계마다 맨 위 「지금 할 일」 카드(할 일 한 문장·상태·다음 버튼), 예시 프로젝트는 "미리 채워져 있음 · 읽기만 하고 다음으로"
- 사용자 지적 "2단계와 4단계가 같은 것 아닌가" → 2단계 = 논문 단위(쓸지 말지, AI 읽기 전), 4단계 = 값 단위(원문과 맞는지, AI 읽은 뒤)를 머리·카드·PDF 설명·판정 도움말에 명시

### 반영하지 않은 것(후속)
- 저자·연도·게재지 서지 칸과 「각주 문구 복사」(u3) — Crossref 메타 조회 필요
- .docx/.hwpx 내보내기(u3) — 다음 판
- 2인 독립 선별·충돌 해소, PRISMA 흐름도(u2) — 도구 범위 밖
- 4단계 저장마다 확인 표시가 풀리는 것(u4·u5) — 근거마다 원문을 읽었다는 표시이므로 유지, 설명만 추가
- 되돌리기(u3·u4) — 이력은 `catalog.json`·`reviews.json`에 남음, 화면 복원 기능은 후속

### 사용자가 직접 보며 준 지적(1차 보고서 뒤)
- "처음에 예시가 다 입력돼 있어 뭘 하라는지 모르겠다" → 「지금 할 일」 카드
- "지금 할 일 카드도 다른 카드와 같아 헷갈린다" → 인디고 바탕·왼쪽 띠·알약 라벨
- "제목에 프로젝트 이름이 올라가 있다, 도구 이름과 설명이 들어가야" / "베스트 사례를 벤치마킹하라" → 제품 머리·진행 표시기·상태 칩·대기열 표(`docs/DESIGN.md` 「0.2.1 배치」)
- "2단계와 4단계가 같은 것 아닌가" → 논문 단위/값 단위를 화면에 명시
- "2단계에서 PDF 등록·학술 자료 찾기가 잘 안 보인다" → 「문헌 추가」 카드로 상시 노출
